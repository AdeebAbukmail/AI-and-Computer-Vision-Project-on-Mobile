# AI-and-Computer-Vision-Project-on-Mobile
It is an AI-based project designed to operate primarily on mobile phones—without the need for a PC—using a computer vision system to control the phone's flashlight.
An offline mobile computer vision project developed in Python, running on Ubuntu Linux within Termux.
How to run the project
# Project Setup and Execution Procedure

### 1. Install Termux and Prepare the Ubuntu Environment

First, install **Termux** on the mobile device and set up an **Ubuntu Linux environment** within Termux. This environment will provide the necessary Linux-based platform for developing and running the project.

### 2. Install Python

Install **Python**, which serves as the primary programming environment required to develop and execute the project.

### 3. Install the Required Libraries

Install the necessary Python libraries required for the project, including:

* **MediaPipe**
* **OpenCV**
* **NumPy**
* **Pillow**

These libraries provide the essential tools for computer vision, image processing, and AI-based functionality.

### 4. Prepare the Project Environment

Create and configure the required project directory and prepare the environment in which the project files and dependencies will be stored.

### 5. Copy and Save the Project Code

Open the **MoCV.py** file, copy the required source code, and paste it into the designated project file. Save the file after pasting the code, then exit the editor.

### 6. Optional: Create a Shortcut for Execution

After completing the setup, you may create a shortcut or command to simplify the process of launching the project in the future.
